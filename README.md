# summerAI - AI Chatbot (Botpress)

An intelligent conversational AI chatbot built using **Botpress** with custom workflows and knowledge base integration.

## Features
- Automated conversational flows and intent handling
- Custom Knowledge Base integration
- Deployed on Webchat

## How to Import & Run
1. Download the `.bpz` file from this repository.
2. Log in to [Botpress Cloud](https://app.botpress.cloud) and create a new bot.
3. Open **Studio**, click the **Botpress Icon** (top-left) > **Import / Export** > **Import from file**.
4. Select the downloaded `.bpz` file to load the entire workflow.
