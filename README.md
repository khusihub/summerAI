# summerAI - AI Abstract & Summary Generator

An intelligent conversational AI chatbot built using **Botpress** designed to generate abstracts and summaries, featuring custom workflows and knowledge base integration.

## Live Demo
👉 **[Click here to chat with summerAI](https://cdn.botpress.cloud/webchat/v3.7/shareable.html?configUrl=https://files.bpcontent.cloud/2026/04/19/17/20260419171917-IBNZLPQI.json)**

## Features
- Automated conversational flows and intent handling
- AI-powered abstract and summary generation
- Custom Knowledge Base integration
- Deployed on Webchat

## How to Import & Run Locally
1. Download the `.bpz` file (`summerAI - 2026 Nov 16.bpz`) from this repository.
2. Log in to [Botpress Cloud](https://app.botpress.cloud) and create a new bot.
3. Open **Studio**, click the **Botpress Icon** (top-left) > **Import / Export** > **Import from file**.
4. Select the downloaded `.bpz` file to load the entire workflow and configuration.
